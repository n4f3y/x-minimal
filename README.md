# x.com minimal ui

userscript for a serene x.com experience

inspo from [@codycollier](https://x.com/codycollier)

## install

1. add [tampermonkey](https://www.tampermonkey.net/) or another userscript manager to your browser
2. [get the userscript](https://raw.githubusercontent.com/n4f3y/x-minimal/main/x-minimal.user.js) and click **install** when prompted
3. reload x.com
